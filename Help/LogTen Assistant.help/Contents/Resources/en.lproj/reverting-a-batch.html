Revert an applied batch

If a batch turns out to be wrong, you can undo it. Applied History keeps a journal of every batch the app delivered, with the changes it made, its verification result, and the import package that carried it.

Revert a batch

  1. Open Applied History in the sidebar and select the batch.
  2. Click Revert Batch… in the inspector, or choose Apply ▸ Revert Batch….
  3. Confirm. The app delivers a compensating batch — one that sets each changed field back to the value it had — and journals it like any other.

Revert Batch… is available only for a batch that was verified and hasn’t been reverted already. A batch that was only recorded never reached LogTen, so there is nothing to revert.

A revert goes through LogTen’s import like the original, and LogTen asks you to confirm it. If you’ve since changed the same fields by hand, check the result in LogTen.
