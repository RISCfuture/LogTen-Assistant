Sync flights from FlySto

FlySto turns the data logs your avionics record into flights with times, tracks and approaches. LogTen Assistant compares those flights with your logbook.

Add your API token

  1. Sign in at flysto.net/account/api and create an API token.
  2. In LogTen Assistant, choose LogTen Assistant ▸ Settings (⌘,) and click Accounts.
  3. Click Set Up… beside FlySto, paste the token, and click Test, then Save.

The token is kept in your Keychain. It is sent only to FlySto. The same pane can store OpenSky Network credentials, if you have an account there.

Sync

Choose Audit ▸ Sync FlySto (⇧⌘R) or click Sync FlySto in the toolbar. A sync fetches the logs added since the last one, then audits again. The Data Sources page shows the number of records, when you last synced, and when you last imported.

Import a CSV export instead

You can use FlySto without an API token. Export your flights from FlySto as CSV, then choose File ▸ Import FlySto Export…, or drop the files on the window. Include the Safari web archive of FlySto’s flight list so the app can link each flight to its page.

Upload data logs

Choose Audit ▸ Upload Data Logs to FlySto…, then Choose Logs…, and pick the files your avionics recorded. FlySto parses them; the next sync brings the results here. This is the one case where a file goes from your Mac to a service, and you start it yourself.
