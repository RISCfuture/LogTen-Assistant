Change the app’s settings

Settings that apply to the whole app are in LogTen Assistant ▸ Settings (⌘,). Settings for one logbook are in its own sheet instead; see Change the settings for one logbook.

Accounts

Credentials for FlySto (an API token) and the OpenSky Network (an API client). Each shows Connected, Saved in Keychain or Not set up. Click Set Up… or Change…, then Test and Save. See Sync flights from FlySto.

Data

  • ADS-B Downloads — where traces are kept (Show in Finder) and how much to keep (Keep up to).
  • Airport Data — Update NASR data automatically.

Track Detection

How the app reads a recorded track to find takeoffs, landings and stops: the Speeds that count as airborne and as on the ground, and the Timing a change must hold for. Restore Defaults puts them back. An aircraft can override them in Logbook Settings.

Updates

How often the app checks GitHub for a new release, whether to include prereleases, and Check Now. See Check for updates.

Advanced

  • When applying fixes — Record the import packages (the default) or Send them to LogTen. Sending needs a disposable test logbook open in LogTen. See Apply fixes to your logbook.
  • Show finding IDs — adds each finding’s identifier to the inspector, for reporting a problem.

The option to send is unavailable until the hidden DisposableLogbookOpen default is set. This is deliberate: declaring it says that LogTen has a disposable logbook open, and from Terminal it is defaults write codes.tim.LogTenAssistant DisposableLogbookOpen -bool YES.
