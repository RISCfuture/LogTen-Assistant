Check for updates

LogTen Assistant keeps itself current: it asks GitHub whether a newer release exists and offers it to you.

Set how often the app checks

  1. Choose LogTen Assistant ▸ Settings (⌘,) and click Updates.
  2. Set Check for updates to Hourly, Daily, Weekly or Never.
  3. Turn on Include prerelease versions if you want beta builds too.

The schedule only runs while the app is open. A prerelease is a release marked as such on GitHub: a build published for testing before it’s declared final. Leave the switch off and you’re offered finished releases only.

Last checked shows when the last check finished. Check Now runs one immediately. The same check is in the app menu as LogTen Assistant ▸ Check for Updates….

Reconsider a version you skipped

When the app offers an update, you can skip that version, and it won’t be mentioned again. Reset Skipped Versions forgets every version you’ve skipped, so each is offered again. It’s dimmed unless you’ve skipped something.

Update with Homebrew

If you installed with Homebrew, you can update the same way:

brew upgrade --cask logten-assistant

You can also download any release from GitHub.

A check is one request to GitHub’s public list of releases. It sends nothing about you, your Mac or your logbook — see What the app sends, and what it doesn’t.
