Apply fixes to your logbook

Applying is deliberately hard to do by accident. Approved fixes go through five safeguards before a single field changes.

Start from Approved

The Approved page lists every fix you marked for correction. When you’re ready, choose Apply ▸ Apply Fixes… (⇧⌘A), or click Apply Fixes… in the toolbar. The command is dimmed until at least one fix is approved.

1. Preflight

The sheet first takes a fresh snapshot and checks each fix against it. It shows what will change, and sets aside anything it can’t safely apply:

  • Can’t Be Imported lists fixes left out — a flight that’s locked or signed, has no flight key, or changed since the audit. The reason is printed beneath each.
  • Change by Hand lists changes LogTen’s import can’t make, with the old and new value and a Copy New Value button, so you can make them in LogTen.

Only a short list of fields has been validated against LogTen’s import. Corrections never touch anything else.

2. Back up

Applying requires a backup. Click Back Up Logbook in the sheet (or choose Apply ▸ Back Up Logbook ahead of time) and the app copies the whole logbook folder, with a manifest of SHA-256 hashes. Backups are listed under Apply ▸ Show Backups in Finder.

You must also tick I made a backup in LogTen’s Backups view. In LogTen, choose View ▸ Backups and click +. LogTen’s own backups are the supported way to restore, because LogTen syncs changes to your other devices.

3. The pilot batch

Fixes go out in batches. The first batch is a single flight, so a problem shows up before the rest are sent. Each row in the Apply section shows where its batch stands. Click Stop After This Batch to stop; batches not yet applied stay approved.

4. Verification

After each batch the app takes a new snapshot and compares it with what the batch should have done. A batch is Verified when every change appears in the logbook and nothing else changed, or marked Verification Failed if not. Open Applied History for the result.

5. Revert Batch

Every delivered batch is journaled with a compensating batch that undoes it. See Revert an applied batch.

Record or send

By default the app records its import packages: it writes them to the logbook’s workspace folder for you to inspect, and does not send anything to LogTen. The sheet’s button reads Record and a count of packages instead of Apply, and approved fixes stay approved, so nothing is lost by trying it.

Sending to LogTen is switched off until you opt in on two counts, because LogTen’s import has been validated only against a disposable logbook:

  • Choose Settings ▸ Advanced and set When applying fixes to Send them to LogTen.
  • Declare that LogTen has a disposable logbook open. The option stays unavailable until you do; see Change the app’s settings.

Once sending is on, LogTen asks you to confirm each import, and ⌘Z cannot undo it. The built-in sample logbook always records.

An automated audit can be wrong. Look at every fix in the sheet before you apply it.
