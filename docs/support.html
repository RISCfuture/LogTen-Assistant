Support

LogTen Assistant · Updated 14 November 2026

Getting help

  • Open an issue on GitHub for a problem, a question or a request.
  • Choose Help ▸ LogTen Assistant Help in the app for the user guide.

When you report a problem

Please include:

  • the version of LogTen Assistant, LogTen Pro and macOS;
  • what you did and what you expected;
  • for a wrong finding, the finding’s ID. Turn on Settings ▸ Advanced ▸ Show finding IDs to see it in the inspector.

Don’t post your logbook or its backups in a public issue.

Questions

Does LogTen Assistant change my logbook on its own?

No. It audits a snapshot copy. It changes the logbook only when you approve fixes and apply them, after a backup, and by default it only records the import packages without sending them to LogTen.

Why can’t it find my logbook?

The app is sandboxed, so it reads a logbook only after you choose its folder. Use File ▸ Open Default LogTen Logbook…, or Open Logbook… for a folder elsewhere. LogTen Pro must be installed in /Applications.

Why does a flight have no aircraft comparison?

Comparisons need evidence for that flight. Sync FlySto or fetch ADS-B data for the days you flew; the Data Sources page shows the coverage for each aircraft.

A currency rule says “Not Checked.”

A rule can’t run when it is turned off, doesn’t apply to your certificate, or needs a field mapped in Logbook Settings. The page names the reason and offers the setting that lets it run.

Can I undo applied fixes?

Yes. Open Applied History, select the batch and choose Revert Batch…. Restoring from LogTen’s own backups is the supported route for anything else.

Does it tell me whether I was legal to fly?

No. It is an aid for reviewing your own records, and each rule says what it can’t see.
